# Roadmap

The roadmap is directional. Each item must pass through a bounded implementation slice with explicit acceptance tests before it becomes a verified capability.

## Near term

- Improve the public repository front door and documentation navigation
- Keep the Life Notebook and recovery path reliable under interruption
- Consolidate capability status and test evidence
- Reduce ambiguity between design documents and implemented behavior
- Add privacy-safe demonstrations using synthetic data

## Later

- Desktop-friendly Mirror interface
- Explicitly governed hosted-model adapters
- Comparable model evaluation and usage records
- Portable backup, restore, and migration workflows
- Documentation website generated from the canonical docs directory
- Domain applications such as BodyFixOS and Project Atlas

HumanOS maintains one active implementation slice and one clearly identified next action to limit unfinished parallel work.
