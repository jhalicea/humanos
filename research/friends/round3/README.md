**Purpose:** Independently stress-test the HumanOS Constitution, Reality Loop, agent architecture, technology stack, security model, and future autonomy model across heterogeneous intelligences.

## Core rule

No FRIEND sees another FRIEND's submission until all independent submissions for that pass are frozen.

The research sequence is deliberately separated to reduce contamination:

1. **Pass A — Blind Constitutional Convention**
   - Input: ratified HumanOS Constitution v0.2 only.
   - Goal: attack rights, authority logic, consent, conflicts, due process, gaps, overreach, under-specification, and transformative-AI failure modes.
   - Architecture and preferred technology choices are withheld.

2. **Pass B — Reality / Architecture / Stack / Security Gauntlet**
   - Input: Round 3 challenge packet plus the frozen Constitution.
   - Goal: break the Reality Loop, agent/swarm model, permission model, storage, memory, isolation, browser/computer control, self-development, stack choices, and recovery logic.

3. **Pass C — Anonymized Tribunal**
   - Input: all frozen submissions with author/provider identity removed.
   - Goal: rank, attack, defend, synthesize, and identify missed failure modes before authorship is revealed.

## Experimental discipline

Each submission records:

- experiment ID;
- pass;
- model/provider self-report;
- runtime-attested identity when available;
- exact input artifact/version/hash;
- whether web access was used;
- whether repository access was used;
- contamination status;
- start/end time when available;
- raw response artifact;
- normalized findings;
- proposed constitutional amendments or architecture changes;
- severity and confidence;
- adjudication status;
- later regression-test mapping.

A participant that has already seen other FRIEND answers or later architecture material may still produce a useful **pilot/calibration** result, but that result is labeled `CONTAMINATED` and is excluded from blind-panel scoring.

## Truth boundary

Research output does not amend the Constitution, alter runtime authority, or prove an implementation. Findings become changes only through the normal HumanOS proposal, review, implementation, test, and ratification/promotion paths.
